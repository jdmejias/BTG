## 2. Desglose Específico por Componente

### 2.1. Tecnología, Infraestructura Cloud & Ecosistema de Datos/IA ($9.0M - 36%)
*El corazón del producto y ventaja competitiva defensible.*
- **Desarrollo de Plataforma Core Banking Modular & APIs ($3.2M):**
  - Implementación de Core Bancario Headless (ej. Mambu / Thought Machine o Core In-house con arquitectura de microservicios en Go/Python/Rust).
  - Integración de rieles de pago regionales (ACH Centroamérica, SINPE Móvil Costa Rica, CoDi/Transferencias Panamá).
  - SDK móvil iOS / Android y portal Web Corporativo.
- **Data Engineering & Infraestructura Cloud MLOps ($2.6M):**
  - Infraestructura Cloud Multi-Zona en AWS / Azure con certificación SOC2 Type II, PCI-DSS Level 1.
  - Data Lakehouse híbrido (Snowflake / Databricks) para streaming de transacciones en tiempo real con Apache Kafka.
  - Plataforma de MLOps (Kubeflow, MLflow, Feast Feature Store) para entrenamiento, versionado y monitoreo de drift de modelos.
- **Modelos Propietarios de Inteligencia Artificial ($2.0M):**
  - *Engine de Credit Scoring Alternativo:* Ingesta de metadata transaccional, facturación electrónica y comportamiento digital (XGBoost + SHAP explainability).
  - *Sistema de Prevención de Fraude & Anti-Money Laundering (AML):* Grafos de conocimiento con Graph Neural Networks (GNN) para detección de ring de colusión y lavado de dinero.
  - *BTG Copilot (Generative Financial AI):* Modelos RAG (Retrieval-Augmented Generation) afinados con directrices de compliance financiero y portafolios de inversión recomendados.
- **Ciberseguridad & Penetration Testing Continuo ($1.2M):**
  - Cifrado homomórfico y en reposo (AES-256), HSMs (Hardware Security Modules) bancarios, auditorías externas semestrales por firmas Tier-1 y Bug Bounty program.

- **Educación Financiera Gamificada & Onboarding ($0.7M):**

### 2.5. Reserva de Liquidez, Garantías & Contingencias ($3.0M - 12%)
*Protección institucional contra imprevistos macroeconómicos o retrasos operativos.*
- **Depósito de Garantía Regulatoria y Encaje ($1.5M):**
  - Fondos restringidos de solvencia requeridos por la autoridad monetaria para inicio de operaciones crediticias y de captación.
- **Buffer para Riesgo de Crédito y Cobertura de Incumplimiento Inicial ($1.0M):**
  - Provisión anticíclica para soportar el aprendizaje inicial del modelo de credit scoring durante los primeros 6 meses sin erosionar el capital operativo.
- **Reserva de Contingencia Operativa ($0.5M):**
  - Liquidez inmediata para emergencias tecnológicas, variaciones en costos cambiarios o aceleración de hitos comerciales imprevistos.
