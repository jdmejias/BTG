# ASSESSMENT CENTER

**Generación BTG & TECH | 2027-1**

## 1. Contexto general

El Banco BTG Pactual se encuentra en un proceso de expansión estratégica hacia Centroamérica, como parte de su plan de crecimiento en Latinoamérica. En este escenario, la organización busca diseñar una estrategia innovadora que permita identificar y desarrollar productos financieros para el nuevo mercado.

Para lograrlo, los equipos contarán con un presupuesto limitado y un tiempo específico para estructurar y presentar su propuesta a los inversionistas, quienes serán los encargados de decidir a qué equipo le asignarán los recursos necesarios para materializar la estrategia.

**La estrategia propuesta deberá:**

* Ser atractiva para jóvenes, familias y empresas.
* Integrar Inteligencia Artificial como ventaja competitiva.
* Ser tecnológicamente viable y escalable.
* Generar rentabilidad.
* Posicionar al Banco como un referente que atrae y desarrolla talento joven.

## 2. Objetivo del ejercicio

Ustedes han sido designados como el Comité Estratégico, responsable de decidir cómo diseñar una estrategia que incluya:

|                  |                                                        |
| ---------------- | ------------------------------------------------------ |
| **PRESUPUESTO**  | Distribución detallada de los $25 millones ficticios.  |
| **PORTAFOLIO**   | Productos o soluciones clave.                          |
| **TECNOLOGÍA**   | Uso efectivo y concreto de Inteligencia Artificial.    |
| **OPERACIÓN**    | Explicación general de cómo funcionaría la solución.   |
| **RENTABILIDAD** | Forma de generar ingresos y sostenibilidad financiera. |
| **TALENTO**      | Estrategia para atraer talento joven.                  |
| **RIESGOS**      | Identificación de los riesgos principales.             |

## 3. Estructura del tiempo (1 hora y 30 minutos)

| TIEMPO     | MOMENTO                      | DESCRIPCIÓN                                                                                                                                                                 |
| ---------- | ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **30 min** | **Presentación del equipo**  | Cada participante dispone de hasta 2 minutos para presentarse brevemente.                                                                                                   |
| **30 min** | **Desarrollo del ejercicio** | Discusión estratégica · Definición de iniciativas · Asignación del presupuesto (tecnología, mercadeo, talento, infraestructura, etc.) · Construcción de la propuesta final. |
| **30 min** | **Presentación final**       | Exposición de la propuesta ante los inversionistas.                                                                                                                         |

## 4. Reglas del ejercicio

* El total invertido no puede superar los $25 millones ficticios.
* El grupo debe presentar una única propuesta final.
* Todos los integrantes deben participar y presentar activamente en la presentación final.
* Cada decisión de inversión debe estar estratégicamente justificada.
